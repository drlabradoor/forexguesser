# Анимация сканирования, брендинг и демо-режим — План реализации

> Выполнен целиком в одну сессию 2026-09-12; галочки проставлены по факту. Порядок задач сохранён — он объясняет,
> почему файлы выглядят именно так.

**Goal:** Привести экран анализа к референсу из промо-ролика (луч по картинке, проценты, фазы), поставить название
«Forex Guesser» в пустые места макета и дать один флаг, которым аккаунт переводится в режим съёмки.

**Architecture:** Прогресс вынесен в чистый модуль `public/js/scan.js` без DOM — он считает проценты и фазу, а
рисование живёт в `screenshot.js`. Решение «доступ есть» переехало в `hasAccess` рядом с `forViewer`: демо-режим
добавил второе поле к условию, и три роута, считающие его по месту, разошлись бы. Подмена профиля делается на
сервере, а не скрытием на клиенте.

**Tech Stack:** Node, Express 4, Postgres (`pg`), pg-mem + Vitest + supertest, TypeScript (`tsc --noEmit`),
фронтенд — ванильный JS с ES-модулями (сборки нет, требование Bothost).

**Spec:** [docs/superpowers/specs/2026-09-12-scan-animation-branding.md](../specs/2026-09-12-scan-animation-branding.md)

## Global Constraints

- **`forViewer` не трогается.** Белый список — единственное место, решающее, что видно без доступа. Демо-режим
  проходит через него как пользователь с доступом, а не в обход.
- **Сквозной тест `e2e/funnel.spec.ts` продолжает проходить без правок логики.**
- **Новая колонка добавляется отдельным `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`.** Правка одного `SCHEMA_SQL`
  не работает: на проде таблица уже существует, и `CREATE TABLE IF NOT EXISTS` её не тронет.
- **Укороченный вывод — только для демо.** Платящий пользователь получает развёрнутый разбор.
- **Пол 2.5 с действует и в демо-режиме.** Иначе анимацию, ради которой всё сделано, не успеют снять.
- **Сборки нет. Новых зависимостей нет.**
- **Стенд визуальной проверки живёт в scratchpad и не коммитится.** Коммиты собираются явным
  `git add <конкретные пути>`; `git add -A` / `git add .` запрещены.

## Структура файлов

| Файл | Ответственность |
|---|---|
| `public/js/scan.js` | Проценты, фазы, пол и догон. Чистая логика, без DOM — поэтому тестируется |
| `public/js/brand.js` | Единственное написание названия |
| `public/js/screens/screenshot.js` | Разметка оверлея и его отрисовка по тикам |
| `src/signals/visibility.ts` | `forViewer` + `hasAccess` — оба решения о доступе в одном месте |
| `src/routes/me.ts` | Подмена профиля в демо-режиме, серверная |
| `src/claude/analyzeChart.ts` | Длина ответа как параметр (`FULL` / `BRIEF`) |
| `src/db/db.ts` | `ADD_COLUMNS_SQL` — идемпотентные добавления колонок |

## Что осталось за рамками

- Карточка результата в стиле референса (большой `SHORT` в малиновом градиенте).
- Рельса шагов из шести узлов — на ширине телефона подписи слипаются.
- Пережатие изображения и смена модели: оба рычага рассмотрены и отклонены в спеке.
