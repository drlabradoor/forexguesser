# Forex Signal Mini App — Спецификация

## Цель

Telegram Mini App: пользователь загружает скриншот графика форекс/крипто пары, Claude Sonnet 5 (vision) анализирует
изображение и возвращает полный торговый сигнал (направление, цена входа, стоп-лосс, 3 тейк-профита). Каждый
пользователь получает **один** бесплатный анализ навсегда. После этого — кнопка-диплинк в личный чат с ботом Николая
за платными сигналами.

## Ключевые решения (зафиксированы в ходе интервью)

1. **Формат** — настоящий Telegram Mini App (WebView, `Telegram.WebApp` JS SDK), не текстовый бот. Один экран для v1,
   без вкладки истории. Визуальный стиль: тёмная тема, кнопка камеры, жёлтый CTA (по референсу "pocket bot"), но без
   его лишних фич (мульти-вкладки, реальный трейдинг).
2. **Поток**: загрузка/съёмка скриншота → `POST /api/analyze` → Claude Sonnet 5 (vision, forced tool-use) → полный
   сигнал (trend, entry, stop-loss, take-profit ×3) + одноразовая анимация роста "баланса".
3. **Лимит**: один бесплатный полный сигнал на Telegram-пользователя **навсегда** (не в день). После использования —
   кнопка "Хочешь больше точных сигналов?" с диплинком в личный чат с ботом Николая (`t.me/<username>`, сам бот вне
   скоупа — только статичная ссылка).
4. **Баланс**: чисто косметический одноразовый эффект в момент выдачи результата — стартовое значение 1000, скачок на
   случайный процент (30–180%) вверх. Не требует персистентности сам по себе, кроме ручного оверрайда через админку.
5. **Дисклеймер**: отсутствует. Явное финальное решение владельца продукта — юридический риск принят осознанно, больше
   не поднимается.
6. **Аудитория**: публичный, монетизируемый с первого дня продукт.
7. **Язык**: только русский (интерфейс и текст сигнала).
8. **Auth**: стандартная валидация Telegram `initData` (HMAC по алгоритму Telegram), доступно любому пользователю
   Telegram, без allowlist.
9. **Хранение**: без БД под содержимое (скриншоты и тексты анализов нигде не сохраняются). Минимальный KV на
   пользователя (таблица `users` в SQLite): флаг "прогон использован", флаг "безлимитный доступ", ручной оверрайд
   баланса.
10. **Админ-панель** (обязательна для MVP), доступ через тот же Mini App (`/admin.html`), auth — проверка
    Telegram ID в таблице `admins`:
    - задать конкретному пользователю произвольное число баланса;
    - вручную выдать безлимитный доступ (снимает ограничение "один прогон");
    - вручную сбросить флаг "прогон использован" (даёт ещё один бесплатный прогон);
    - только владелец (ID из `OWNER_TELEGRAM_ID`) может добавлять новых админов; обычные админы — не могут.
11. **Модель**: `claude-sonnet-5` для анализа графика (не Haiku) — качество распознавания графика и согласованности
    уровней entry/stop/take-profit напрямую определяет конверсию в переход к Николаю; разница в стоимости на объёмах
    "один бесплатный прогон на юзера" пренебрежимо мала.

## Вне скоупа (осознанно исключено)

- Реальная интеграция рекламных сетей (Adsgram/Monetag/"колесо") — идея обсуждалась и отклонена.
- Хранение истории скриншотов/анализов, вкладка истории.
- Реализация самого бота Николая — только статичная диплинк-кнопка на него.
- Любые дисклеймеры или предупреждения о финансовых рисках.
- Allowlist/приглашения — приложение полностью публичное.

## Данные

Таблица `users`: `telegram_id` (PK), `free_run_used` (bool), `unlimited_access` (bool), `balance_override`
(nullable number), `created_at`.

Таблица `admins`: `telegram_id` (PK), `added_by` (nullable), `created_at`. Владелец сидируется из
`OWNER_TELEGRAM_ID` при старте сервера.

## API

- `GET /api/config` — публичный, отдаёт `{ nikolaiBotUrl }`.
- `GET /api/me` — требует `initData`, отдаёт `{ alreadyUsed }`.
- `POST /api/analyze` — требует `initData`, тело `{ imageBase64, mediaType }`, отдаёт `{ signal, balance }` или
  `403 { error: "ALREADY_USED" }`.
- `GET /api/admin/users`, `POST /api/admin/users/:id/balance`, `POST /api/admin/users/:id/unlimited`,
  `POST /api/admin/users/:id/reset`, `POST /api/admin/admins` — все требуют `initData` + членство в `admins`;
  `/admins` дополнительно проверяет, что вызывающий — владелец.
